在 .vscode/launch.json 加一个 attach 配置
   {
     "version": "0.2.0",
     "configurations": [
       {
         "name": "Python: Attach 5678",
         "type": "python",
         "request": "attach",
         "connect": {
           "host": "127.0.0.1",
           "port": 5678
         },
         "justMyCode": false
       }
     ]
   }
在 Run and Debug 里选 Python: Attach 5678
点启动调试即可
